# Git Workflow

## Branch Strategy
main → stable, tested code
feature/xxx → নতুন feature develop

## Commit Message Format
feat: add upload screen
fix: bKash payment error handling
style: improve report card UI
chore: update dependencies

[ ] Error case test করেছি
[ ] Code বুঝেছি
[ ] Commit করেছি
